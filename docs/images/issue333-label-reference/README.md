# #333 政治ラベルの参考画像（案A）と reference / before / after 比較

Issue #333（「修正 issue を何度積んでも参考画像のような国名ラベルにならない」）
の完了判定を第三者が再確認できるようにするための証跡。

**この Issue の要点は「参考画像そのものを固定比較の対象に据える」こと**である。
#267 は参考画像を「表示階層の参考」へ弱め、#308 は「1.2px 以上」、#322 は 「#308
の 1.3 倍」「1.6〜2.6px」を合格基準にした。いずれも**参考画像との一致を
基準にしていない**。ここには参考画像そのものと、reference / #322 before / after
を同じ倍率で並べた比較画像を置く。

## 本番実測（AC15 の承認時点）

方式（細い外縁 + 文字列単位の濃色プレート）は参考画像に到達しており、#322 で
潰れていた 12px のカウンターも開いた。承認時に「残差」として挙がった 3 点の
うち、**主要な 1
点は再実測の結果、計測アーティファクトで実在しないと判明した**。
ここに経緯を残す（同じ測り方を繰り返さないため）。

### 実在しなかった残差: 「緑地でプレートが参考画像の約 6 割しか沈まない」

承認時には、比較画像のラベル**中央 1 行**の輝度から次を得て「緑地でだけ沈みが
足りない」と判断していた。

| 条件                        | 地色 | プレート |     差 | 実効 alpha |
| --------------------------- | ---: | -------: | -----: | ---------: |
| 参考画像 / HRE（緑地）      |  157 |      120 | **37** |      ≈0.31 |
| after 本番 / HRE（緑地）    |  152 |      131 | **21** |      ≈0.19 |
| 参考画像 / ノルマンディー   |  186 |      155 |     31 |      ≈0.21 |
| after 本番 / ノルマンディー |  198 |      167 |     31 |      ≈0.19 |

**この 37 は実在しない。** 原本 `reference-plan-a.png` を 13 標本（緑地 4 / 明地
9）で測り直すと、参考画像のプレートは**地色によらず一定 alpha**で、
緑地と明地の差は −0.006 ± 0.017（t = −0.35）＝有意差ゼロだった（詳細は
[`docs/research/issue-333-label-reference-targets.md`](../../research/issue-333-label-reference-targets.md)
§2.4）。

差 37 を生んだ原因は 3 つ重なっている:

1. **グリフ halo の混入（最大要因、約 −6）** — 120 は「神」の SDF 外縁の裾を
   拾った値。清浄なプレート面は 126〜128。
2. **単一行サンプル（約 −6）** — 羊皮紙テクスチャの σ ≈ 5。プレート全行で
   平均すると外側は 157 ではなく 153.4。
3. **参考画像側と after 側で規則が非対称** — after では halo を避けた平坦部を
   平均しているのに、参考画像側では最深部を採っていた。

同じ規則で帯平均すると **参考画像 Δ 24.8（α ≈ 0.216）/ 本番 after Δ 26.5 （α ≈
0.225）** で、**本番の方がむしろわずかに強く沈んでいる**。x4 拡大・ nearest
補間・PNG は無罪（各ソース画素が 4 回複製されるだけで値は不変）。

手法の妥当性は、真値 α = 56/255 が既知の本番 after を対照にして確認した。
**プレートの沈み量を測るときは、必ずプレート矩形の行方向で帯平均し、グリフ ink
bbox の 4px 手前・プレート端から 3px 内側までに限ること。** 単一行・
グレースケール一本化はこの信号量では使えない。

### 見送った残差 2 点（いずれも要再実測）

- パディングと角丸が参考画像より小さく見える件。ただし
  `issue-333-label-reference-targets.md` は左右余白 0.275 em・角丸 0.28 em と
  実測しており、`src/labels_test.ts` はその比 0.25〜0.36 を固定していて現行の
  padding 5 / radius 5（下位段 4/4）はレンジ内。**上の残差 1 と同じく、
  拡大画像の目測で判断しないこと。**
- プレート外側の柔らかい影／グローが無い件（実装は 1px のクリーム線で終わる）。

### 回帰と性能

DPR2 比較で before / after のラベル位置・ラベル集合が 1px も動いていない
（`prod-cmp-z5-y1100-dpr2.jpg` が最も明瞭）。プレート自体は既存の衝突用
クアッド（`background: true`）の色替えである。

ただし **「描画要素が増えていない」は厳密には不正確**で、AC3
のために政治ラベルの TextLayer が 1 枚 → 2 枚（top /
lower）に分割されている。実測（before = `e51a1b1` / after = `3c36f25`
を個別にビルドして比較）:

| 指標                     |        before |               after |
| ------------------------ | ------------: | ------------------: |
| SDF アトラス数           |             2 |       2（増減なし） |
| アトラス初回生成（合計） |       109.0ms |    110.6ms（+1.5%） |
| パン中 draw call / frame |        264.24 | 267.29（**+3.05**） |
| パン中 fps               |         59.83 |               59.86 |
| フレーム間隔 p50 / p99   | 16.7 / 16.8ms |       16.7 / 16.8ms |
| 年代切替                 |     610–635ms |           606–630ms |
| GC 後 JS heap            |        46.6MB |              46.8MB |

draw call の +3 は TextLayer 1 枚増ぶんで、レンジが重ならないため実在の差。
ただしフレーム時間は vsync 上限に対して変化せず、DPR2 でも GPU 律速に至って
いない（AC10
の「顕著な退行がない」を満たす）。注記系（都市・河川・山岳・山峰）の アトラスは
1024x1024・101 グリフで before/after 同一で、AC9 も満たす。

## 再生成

```fish
# 1) 地色を本番と揃えるためタイルを取得してから dist を作る
deno task build
curl -sS -o dist/europe.pmtiles https://tiles.zeitreises.com/europe.pmtiles
curl -sS -o dist/europe-dem.pmtiles https://tiles.zeitreises.com/europe-dem.pmtiles
deno task serve --port 8333

# 2) 各ビューを撮る（DPR 2 は --device=desktop-hidpi。#320 の
#    --force-device-scale-factor 経路が無いとラベルが 1 つも描画されない）
deno run -A scripts/verify/cdp.ts "http://localhost:8333/?year=1100&zoom=5&center=10.0,49.5" <撮影スクリプト>
deno run -A scripts/verify/cdp.ts --device=desktop-hidpi "http://localhost:8333/?..." <撮影スクリプト>
```

撮影スクリプトは `?year=<Y>&zoom=<Z>&center=<lon>,<lat>` へ navigate →
`waitForAppReady` → `window.__getYear() === <Y>` を waitFor → 3 秒待って
`api.screenshot()` を回すだけの使い捨てハーネス。撮影に使ったビューは z4 =
`8.0,48.0` / z5 = `10.0,49.5` / z7 = `10.5,48.5`。

**before 側の再現**は `src/labels.ts` の `POLITICAL_LABEL_STYLES` を #322 相当
（両グループとも `outlineWidth: 12` / `plateColor: [0,0,0,1]` /
`plateBorderWidthPx: 0` / `platePadding: [0,0,0,0]` /
`plateBorderRadiusPx: 0`）へ差し替えて再ビルドすれば得られる。この差し替えは
**#333 で追加した固定標本テスト 7 件を red
にする**（`deno test
src/labels_test.ts src/political_layers_test.ts` → 125
passed / 7 failed）ので、 「before
に戻すとテストが落ちる」ことも同時に確認できる。
