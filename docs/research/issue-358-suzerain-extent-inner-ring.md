# 勢力圏外枠のクロニアン潟内環の素性と対処可否（Issue #358）

- 調査日: 2026-08-15
- 契機: Issue #358（#330 / PR #351 のマージ後動作確認で見つかった残差。1815 年
  プロイセン選択時、緑青のアクティブ領域の内部に孤立した短い臙脂線が残る）
- 使用データ: `data/europe_<year>.geojson`・`data/coastal_fill_<year>.geojson`
  （いずれもコミット済みの配信データ）と、露出判定のための OpenStreetMap
  `natural=coastline`（ODbL, Overpass API。bbox `54.9,20.3,55.6,21.4`・11,499
  セグメント）
- 結論の反映先: `docs/data-inventory/README.md` §3.14（データ台帳側の本文）・
  `docs/app-spec.md`（外枠の節の注記）・`src/suzerain_extent_coastal_test.ts`
  （現状の内環構成を固定する特性テスト）

## 1. 結論

**対処せず、既知の残差として記録する（Issue #358 の対処候補 (c)）。**

理由は、この臙脂線が「表示境界と一致しない概略海岸線」ではなく、**画面に実際に
塗られている面（沿岸補完の帯）の縁そのもの**だと実測で確定したためである。 #330
AC4 が禁じたのは前者であり、本件は字義上その違反ではない。外枠側だけで
線を消すと、線と塗りが再び食い違う（#330 が却下案 2 として明示的に避けた状態に
戻る）。

原因は帯の生成側（`coastalBandPolygon`
の片側オフセットが粗い海岸線で折り返す）に あり、対象は 1815 年に限らず 17
年代に及ぶ。是正するなら帯の生成を直すべきで、 それは配信データ 19
年分の作り直しを伴う別タスクになる。

## 2. 内環の素性（実測）

1815 年プロイセンの外枠（`buildSuzerainExtent` に事前生成の帯を渡したもの）は
内環を 8 本持つ。うち Issue が指す 2 本は次のとおり。

| 環 | 頂点数 | 面積      | 周長     | 平均半幅  | bbox                            |
| -- | ------ | --------- | -------- | --------- | ------------------------------- |
| r7 | 10     | 188.7 km² | 75.22 km | 2,508.3 m | `[20.746,55.248,21.067,55.520]` |
| r8 | 6      | 62.2 km²  | 56.70 km | 1,096.7 m | `[20.754,55.101,20.944,55.327]` |

Issue が挙げた「平均半幅 1096m・周長 56.7km・面積 62km²」は r8 に一致する。
確認できた事実は 3 つある。

1. **歴史ポリゴン側に対応する穴は無い。** `data/europe_1815.geojson` の
   `NAME=Prussia`（東プロイセン側は feature 添字 100）は経度 19 度以東に内環を 1
   つも持たない。したがってこの内環は「クロニアン潟に相当する歴史ポリゴンの
   穴」ではない。
2. **帯の穴と頂点集合が完全に一致する。** `data/coastal_fill_1815.geojson` の
   feature 76（`baseIndex: 100`）の poly0 は穴を 2 本持ち、それぞれ r7 / r8 と
   頂点集合が一致する。つまり緑青の塗り（沿岸補完の帯）にも同じ穴が空いており、
   臙脂線はその塗りの縁をなぞっている。
3. **帯の穴は片側オフセットの折り返しで生じている。** 環の内部は `europe_1815`
   のどの政治ポリゴンにも属さず（全辺の中点で `booleanPointInPolygon` が 0
   件）、最寄りの沿岸 run（東プロイセンのラグーン 東岸）までは 14.9〜23.8 km と
   `COASTAL_FILL_BAND_KM = 30` の内側にある。
   にもかかわらず帯に入らないのは、当該区間の海岸線が
   `(21.216,55.344) → (21.201,55.261) → (21.143,55.256) → (21.224,55.111) →
   (21.113,55.089) → (21.192,54.960)`
   と 5〜13 km 刻みで東西にジグザグしており、 外向き 30 km
   のオフセット列が折り返して巻き数が打ち消し合うため。実際、 この run
   から作った素の帯ポリゴン（`coastalBandPolygon`、差分前）に対して
   環の内部点を判定すると、巻き数・奇偶のどちらでも「外」になる。

### 2.1 年代横断

この 2 環は東プロイセンの海岸線が年代間で使い回されているため、**19 年代のうち
17 年代**で同じ形のまま現れる（1000 年 Prussians / 1279〜1500 年 Teutonic
Knights / 1530〜1815 年 Prussia / 1880・1900 年 Germany / 1914 年 German
Empire。面積・周長・bbox はすべて同一）。1815 年固有の現象ではない。

より広く、全 19 年代 × 全宗主キーの外枠が持つ内環 2,421 本のうち 1,733 本は base
ポリゴンの頂点を 1 つも含まない（= 帯だけで囲まれた環）で、うち平均半幅 500 m
以上が 750 本ある。折り返し由来の穴は本件だけの特殊事情ではなく、帯の
生成規則そのものに由来する。ほとんどは沖合にあり海洋 `water`
に覆われて見えない。

## 3. 画面上の残差の大きさ（実測）

露出判定は OSM の `natural=coastline`（陸が進行方向左、という OSM の規約）を
使い、環の周に沿って 50 m 刻みでサンプルした各点が陸側か海側かを最近傍
セグメントの向きで判定した。

| 環 | 周長     | 現代の陸に乗る長さ   | 露出区間                                                                                     |
| -- | -------- | -------------------- | -------------------------------------------------------------------------------------------- |
| r7 | 75.35 km | **0.00 km（0.0%）**  | なし（全周が水面下）                                                                         |
| r8 | 56.71 km | **7.75 km（13.7%）** | `[20.754,55.101]`〜`[20.756,55.117]` 1.80 km と `[20.794,55.149]`〜`[20.754,55.101]` 5.95 km |

2 本の露出区間は環の南西角 `[20.754,55.101]` で接するので、画面上では 1 つの V
字として見える。位置は Issue の報告（lon ≈ 20.77 / lat ≈ 55.09〜55.15）と一致
する。環の内部 62.2 km² のうち現代の陸は 2.08 km²（3.3%）だけで、残り 96.7% は
クロニアン潟・バルト海の水面下にあり `water` に覆われる。

ズーム段ごとの見え方（MapLibre は 512px タイルなので緯度 55.2° の分解能は
`40075016.686 × cos(55.2°) / (512 × 2^z)`）:

| ズーム | 分解能     | 露出 7.75 km の長さ | 長い方の 1 本（5.95 km） | 砂州上の未塗り面 2.08 km² |
| ------ | ---------- | ------------------- | ------------------------ | ------------------------- |
| z5     | 1,396 m/px | 5.5 px              | 4.3 px                   | 約 1.1 px²                |
| z6     | 698 m/px   | 11.1 px             | 8.5 px                   | 約 4.3 px²                |
| z7     | 349 m/px   | **22.2 px**         | 17.0 px                  | 約 17 px²                 |
| z8     | 175 m/px   | 44.4 px             | 34.1 px                  | 約 68 px²                 |

z7 の 22.2 px は Issue がスクリーンショットの連結成分解析で測った「約 22px」と
一致する（Issue が併記した「≈ 14km」は 256px タイル前提の分解能で換算した値で、
実長は 7.75 km。#312 の調査が指摘したのと同じ換算の取り違え）。露出区間全体の
bbox は `[20.754,55.101,20.794,55.149]` = 2.55 × 5.31 km で、z7 では 7.3 × 15.2
px、z5 では **1.8 × 3.8 px** に収まる。z5 では線幅（`HRE_EXTENT_LINE_WIDTH_PX` =
3px）そのものと同じ桁で、V 字ではなく点にしか見えない。

## 4. 各案の検討

### (a) 現代の水域に大半が覆われる内環を除外する — 不採用

- **実行時判定は採れない。** ベースマップはベクタタイルで、`water` /
  `water-inland` の幾何を実行時に取得できない（#330 で確認済み）。
- **事前生成側の判定材料もリポジトリに無い。** `data/` に現代の水域・海岸線の
  ジオメトリは 1 つも無く、`coastal_fill_<year>.geojson` は
  `europe_<year>.geojson` だけから作られる（`scripts/build-coastal-fill.ts` の
  入力はネットワーク不要の既存生成物のみ）。ベースマップ本体
  （`europe.pmtiles`）はコミットしておらず（`.gitignore`）、生成には外部の
  `pmtiles` CLI が要る。本調査が使った OSM coastline や Natural Earth 10m を
  新たなビルド入力として持ち込むことは技術的には可能だが、それは「沿岸は
  ベースマップの `coastline` と海洋マスクに担わせる」という #330 の表示方針
  （#358 でもスコープ外と明記）に対して、**もう 1 つの海岸線の権威を
  パイプラインへ持ち込む**ことになる。判定に使う海岸線と実際に覆う海岸線が
  別物である以上、「覆われるはず」と判定した環が実際には露出する取りこぼしが
  残り、残差 7.75 km と引き換えに合わない。
- なお本件では、**露出しているのはまさに「水域に覆われない部分」**なので、 (a)
  が消せるのは「環ごと落とす」判断をした場合に限られる。その場合の副作用は (b)
  と同じ（後述）。

### (b) 内環の露出区間だけを間引く — 不採用

- 露出区間を知るには (a) と同じ現代水域データが要る（同じ理由で不可）。
- 仮に区間を特定できたとしても、**この内環は塗り（帯）の穴と同一**なので、線を
  間引くと「塗りだけの段差が残る」という #330 の却下理由がそのまま当てはまる。
  #358 は「外環ではなく内環に限れば事情が異なる可能性」を挙げたが、実測では
  内環の方がむしろ塗りと厳密に一致している（§2 の 2）ため、事情は同じどころか
  より不利になる。
- 環ごと落とす（穴を埋める）場合も同様で、臙脂線は消える代わりに、砂州上の 2.08
  km² が「緑青に塗られていないのに外枠の薄い臙脂の塗りには入っている」
  状態になり、線と塗りの整合という #330 の採用理由を自ら崩す。

### (c) 許容する — 採用

- 残差は z7 で 22 px・z5 で 5px 相当、露出は環周長の 13.7%（7.75 km）だけで、
  #330 が消した乖離（1815 年プロイセンでアクティブ面の 8.78% = 24,737 km²）とは
  4 桁以上小さい。
- 臙脂線は見えている塗りの縁と一致しており、#330 AC4 の字義（一致させない区間で
  概略海岸線を残さない）には違反していない。「孤立して見える」のは、同じ環の
  残り 96.7% が水面下で見えないためである。
- 本当の欠陥は帯の穴（塗りの欠け）であり、直すなら
  `src/coastal_fill.ts coastalBandPolygon` の片側オフセットが折り返しても穴を
  作らない構成（セグメントごとの矩形＋継ぎ目円弧の union など）へ変える。 影響は
  19 年代の `coastal_fill_<year>.geojson` の作り直しと、#312 / #313 で
  確認した自己交差・二重塗りの再検証に及ぶため、#358 の枠では扱わず別タスクと
  するのが妥当。

## 5. 再現手順

`data/` のコミット済みファイルだけで再現できる（露出判定のみ Overpass API を
使う）。

```sh
# 内環の一覧（1815 年プロイセン）
deno test --allow-read=data,docs,src,scripts,index.html,app.css,.github/purge-paths.txt \
  --allow-env=NODE_ENV src/suzerain_extent_coastal_test.ts
```

`src/suzerain_extent_coastal_test.ts` の
「クロニアン砂州沖の内環は沿岸補完の帯の穴と同一（#358 既知の残差）」が、環の
本数・平均半幅・帯の穴との一致を固定している。露出長 7.75 km を測り直す場合は、
Overpass で `way["natural"="coastline"](54.9,20.3,55.6,21.4)` を取得し、環の周を
50 m 刻みでサンプルして最近傍セグメントの左右で陸海を判定する（本文 §3）。
