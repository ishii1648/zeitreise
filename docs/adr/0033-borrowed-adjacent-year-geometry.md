# decision-33: 上流に面が無い年へ隣接年の出典付きジオメトリを流用する条件（ADR-0014 / ADR-0018 の限定的な例外）

## Context

ADR-0014（出典を持たない座標合成は行わない）と ADR-0018（現代県ポリゴン
合成の禁止）は、欠落を埋めるより「描かずに説明する」ことを選んできた。
ADR-0018 はその本旨を**「座標の出所」ではなく「地図が主張する内容の出典」**
に置いている——県 union の座標は IGN まで遡れるが、1200 年の境界としての
出典はゼロだから不可、という判断である。

この基準の下で、本ループは実際に複数の欠落を「埋めない」と判断してきた:

- **#189**: 1530 / 1600 / 1650 年のハンガリー王国。OHM の AL2 連鎖
  （1401〜1751）は label ノードのみで境界 way がゼロ。
- **#190**: 1650 / 1700 年のスペイン領ネーデルラント（rel 2848630 /
  2848632）とブラバント公領（2812126）。同じく label ノードのみ。
- **#187**: ブラバント公領（近世）。同上。

一方 #202 は、1492 年のオーストリア大公領・ミラノ公国について
**隣接年 1500 の出典付きジオメトリを流用する**方針をユーザー承認済みで
持っている（`data/hre_1500.geojson` の `Archduchy of Austria`、
`data/italy_fiefs_1500.geojson` の `Duchy of Milan`）。1492 年はこの 2 政体が
上流のいずれにも面を持たない一方、1400 年と 1500 年には表示される「1492 年
だけの穴」であり、史実上もマクシミリアン 1 世の世襲領統合直後・スフォルツァ
家の最盛期にあたる。

この流用は、座標の出所（Roller / OHM rel 2800654）は追跡できるが「1492 年の
境界としての出典」はゼロであり、**ADR-0018 の文言に照らせば禁止側に当たる**。
両者の関係を決めないまま実装すると、以後の欠落判断の基準が失われる。

## Decision

**隣接年の出典付きジオメトリの流用は、ADR-0014 / ADR-0018 の本旨を維持した
うえでの限定的な例外として認める。**位置づけは「本旨の再解釈」ではなく
**明示的な例外**であり、次の 4 条件を**すべて**満たす場合に限る。

1. **対象年に面が存在しない**。採用済みソース（historical-basemaps / OHM /
   Cliopatria / Roller）のいずれにも、その年のその政体の面が無いこと。
   面があるなら流用しない（既存の収録が常に優先する）。
2. **借用元が出典付きの実在ジオメトリである**。既に本リポジトリが採用し
   生成物として持っている面（ファイル + relation id / ソース識別子まで
   特定できるもの）に限る。新たな座標の合成・編集・単純化しての流用は
   一切行わない（ADR-0014 の禁止はそのまま効く）。
3. **政体の同一性と領域の連続性が史実で確認できる**。借用元の年と対象年で
   同じ政体が同じ領域を支配しており、その間に地図の縮尺で見て有意な領域
   変動が無いこと。支配者の交代・戦争による大規模な版図変動・政体の断絶が
   間に挟まる場合は該当しない。
4. **年差が 1 スナップショット区間以内**。隣接するスナップショット年からの
   借用のみを認める（本プロジェクトの年代刻みでは最大でも十数年）。
   離れた年からの借用は、条件 3 を満たしていても認めない。

さらに、流用する場合は**借用の事実を必ず開示する**（後述の追跡可能性）。
開示により、地図が主張する内容は「1492 年の境界」ではなく
**「1500 年時点の出典付き境界を 1492 年の近似として示したもの」**に変わる。
出典なき主張をしないという ADR-0018 の本旨は、この開示によって担保される。
開示を伴わない流用は本 ADR の対象外であり、禁止のままである。

### 適用例（この基準で判別できること）

| 事例 | 条件 1 | 条件 2 | 条件 3 | 条件 4 | 判定 |
| --- | --- | --- | --- | --- | --- |
| #202: 1492 オーストリア大公領 ← 1500 | ○ 1492 に面なし | ○ `hre_1500.geojson` の実在面 | ○ 同一ハプスブルク世襲領・8 年差で有意な変動なし | ○ 隣接年 | **流用可** |
| #202: 1492 ミラノ公国 ← 1500 | ○ | ○ `italy_fiefs_1500.geojson`（OHM rel 2800654） | ○ スフォルツァ家の継続支配 | ○ | **流用可** |
| #189: 1530〜1650 ハンガリー王国 | ○ 面なし | **✕** 借用元自体が存在しない（AL2 連鎖は label ノードのみ）。AL3（1779〜）は形態も領域も別 | ✕ 中央ハンガリーはオスマン占領下で領域が全く異なる | ✕ 130 年超 | **流用不可**（known-limitations 記録） |
| #190: 1650 / 1700 スペイン領ネーデルラント | ○ 面なし | **✕** 全年で境界 way ゼロ | — | — | **流用不可**（同上） |
| #187: 近世ブラバント公領 | ○ | **✕** 同上 | — | — | **流用不可**（同上） |

条件 2 が最初の関門になる: #187 / #189 / #190 で「埋めない」と判断した
ケースは、そもそも借用できる面がどの年にも存在しなかった。本 ADR は
これらの判断を覆さない。

### 追補

- **ADR-0035（借用ジオメトリの表示は差引済み flat 派生物とする）**: 条件 2 の
  「座標を 1 頂点も変えない」は借用元ファイルに対して維持し、配信・描画は
  既存 7 系統と同じ差引済み flat 派生物で行う。
- **ADR-0039（上流データセットの隣接区間からの年借用 / CC BY 4.0 の入力）**:
  条件 2 の借用元を「本リポジトリの生成物」から「コミット SHA とアーカイブの
  SHA-256 で特定できる上流データセットの実在区間」へ広げ、条件 4 の「隣接
  スナップショット年」を「上流区間の隣接」まで広げる。あわせて
  `BASE_FIEF_SPLITS` の入力に CC BY 4.0（Cliopatria）を認める。適用例は
  #346（1200 年のボヘミア王国 ← 上流 [1202-1215]）。

## Consequences

### 追跡可能性（借用の開示）

流用した feature は、次の 3 箇所すべてで借用であることを追跡できるように
する。

- **生成物の metadata**: 借用元の年・ファイル・relation id（またはソース
  識別子）を feature の properties か、ファイル単位の `metadata` に記録する
  （既存の `source` / `sourceUrl` / `license` / `borderPrecision` と同じ層。
  `scripts/build-attribution.ts` の刻印対象に含める）。キー名と粒度は実装
  タスク（#202）で決め、テストで固定する。
- **UI での開示**: `data/known-limitations.json` に年代連動エントリを置き、
  その年の地図を見ている利用者に「この政体の境界は隣接年の出典から流用した
  近似である」ことが読めるようにする（#175 の summary + text 形式）。
- **台帳**: `docs/data-inventory/missing-powers-ledger.md` の該当行を
  「借用で表示」と明記し、上流が埋まれば解消できる行として残す。

### 上流が埋まった場合の差し替え

借用は暫定措置である。上流（OHM 等）に対象年の面が現れたら、
借用エントリを許可リストから外して通常収録に切り替え、metadata・
known-limitations・台帳の記載も同時に落とす。差し替えの検知は
既存の実測手順（Overpass 照会）に依存し、定期自動化はしない。

### 波及

- 「作れるものは作る」への後退ではない。合成（新しい座標を作る）は
  引き続き全面禁止であり、本 ADR が認めるのは**既存の出典付き座標を、
  由来を明示して隣接年へ流用すること**だけである。
- 条件 3（領域の連続性）の判断には史実の裏取りが要る。判断が割れる場合は
  流用しない側に倒し、known-limitations に記録する（ADR-0014 の既定に戻る）。
- 関連 ADR: 0014（出典なき座標合成の禁止）・0018（本旨を「主張の出典」へ
  適用）・0028（切り出しと propertyFixes の併用）。関連 Issue: #202（実装）・
  #187 / #189 / #190（流用しなかった事例）。
