# decision-30: 衝突参加の全ラベル層に不可視背景クアッドを敷き自己衝突を構造的に防ぐ

## Context

CollisionFilterExtension（deck.gl 9.3.7）の可視判定は「衝突 FBO 上の
自アンカー画素（±2px の 5x5 サンプル、TASK-108 の二値化後は 25 中 ≥19 の
自己一致が必要）が自分の描画で占められているか」を見る。TASK-72 で背景
パネルを撤去して以降、背景の無い TextLayer は衝突 FBO にグリフの字形しか
残さない（SDF の透明部は picking 系シェーダの alpha==0 discard で描かれ
ない）。そのため**アンカー画素がグリフのインクに当たらないラベルは、自分
自身の可視判定に永遠に失敗して一度も描画されない**。

TASK-136 は河川層の「ライン川」（偶数 4 文字でテキスト中央が文字間空白）で
この機構を実証し、河川層のみ背景クアッドで対処した。TASK-143 の全層監査
（実表示テキスト 1146 件の静的走査 + 1000/1200/1300 × z4〜z7 の実機
オーディット）で、該当が河川に限らないことが確定した:

- **一度も描画されないラベル 11 件**: 都市 10 件（ローマ・ボローニャ・
  ルーアン・カイセリ・ヴェリコ・タルノヴォ・メス・ソルターニーイェ・
  ヘレス・デ・ラ・フロンテーラ・カン・イーペル）+ 勢力 1 件（1300 年の
  ボヘミア王国）。
- 失敗パターンは 2 系統: (1) 偶数文字数で中央が文字間空白（ルーアン =
  ー|ア、ボヘミア王国 = ミ|ア）、(2) **中央グリフが「ー」「・」で
  アンカー行にインクが無い**（ローマ・ボローニャ等。都市・山峰は
  getPixelOffset で文字列がアンカーの上へずれ、アンカー行がグリフ下部に
  あたるため「ー」の横棒から外れる）。衝突サンプル点は getPosition の
  投影位置で pixelOffset に追従しないことを deck.gl ソースで確認した。
  **TASK-136 時点の仮説「偶数文字数×中央空白」は必要条件ではなかった**。

## Decision

**衝突に参加する全ラベル層（勢力・都市・山脈・山峰ラベル・河川）に、
ほぼ不可視（alpha 1/255）の背景クアッドを敷く。**`src/labels.ts` の
`LABEL_COLLISION_BACKGROUND_COLOR` + `labelCollisionBackgroundProps()` を
単一の定義元とし、`main.ts` の `labelLayerBaseProps` で展開する（TASK-136
の河川個別対処は base props へ移設して撤去）。背景クアッドがテキスト矩形
ぶんの衝突 FBO 実体を作るため、可視判定が字形の隙間に依存しなくなる。

- alpha 0 は picking 系シェーダの discard で FBO に描かれないため 1 が下限。
- 衝突に参加しない層（山峰マーカー ▲）には敷かない。
- `labelTextStyleProps` は `background: false` のまま維持し、TASK-72 の
  「見える背景パネルは持たない」描画契約と両立させる（スプレッド順で
  衝突対策側を後にする）。

却下案:
- **該当ラベルのみ個別対処**: 被疑の大半が都市でアンカー = 都市座標・
  テキストとも不変にできず、データ追加・訳変更のたびに再発する。
- **記録のみ**: ローマ級の最重要都市が永遠に表示されないのは実害。
- **COLLISION_SIZE_SCALE の再調整で補償**: decision-21（衝突二値化）の
  前提と衝突し、全ラベルバランスの再検証が必要。将来の選択肢として残す。

## Consequences

- 衝突挙動が「字形の隙間頼み」から「テキスト矩形」ベースへ一方向に変わる。
  実機 before/after（69 ビュー）では被疑 11 件が全て描画される一方、表示
  総数はほぼ全ビューで同数以上（減少は 4 ビューで各 -1）。相手の字形の
  隙間に偶然乗って出ていた低優先ラベル 17 ビューケースは優先度どおり
  間引かれるが、いずれも隣接ズーム段で表示される。
- 新規データ・新規ラベル層にも構造的に有効（中央グリフの形に依存しない）。
  新しいラベル層を追加する場合は `labelLayerBaseProps` を使うこと。
- ラベルの見た目は不変（alpha 1/255 は目視で識別不能。スクリーンショット
  比較で確認済み）。

> **追記（ADR-0038）**: 政治ラベル 2 層に限り、このクアッドの色・余白・角丸を
> 差し替えて**可視の濃色プレート**にしている。クアッド自体は存在し続けるため
> 本 ADR の目的（自己衝突の構造的回避）は損なわれない。注記ラベル（都市・
> 河川・山岳・山峰）は不可視値のまま。
