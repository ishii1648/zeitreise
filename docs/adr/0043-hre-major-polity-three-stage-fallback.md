# decision-43: HRE主要領邦は同年面・許可済み借用面・境界未収録点の3段階で表す

## Context

HRE領邦の上流データは年代ごとに収録密度が異なる。史実上存続する領邦でも、
スナップショット年の面が無いだけで地図から消えていた。一方、離れた年代の面を
自動流用したり周辺領邦から形を合成したりすると、出典のない版図を断定する。

ADR-0033 / ADR-0039 は、史実上の連続性を個別に確認した隣接年の出典付き面を
座標無改変で借用できる条件を定めている。本判断は、借用条件を満たさない場合にも
政体の存在を無言で落とさない表示契約を追加する。

## Decision

- `data/hre-major-polities.json` を再生成可能な期待値台帳とする。安定ID、英日名、
  称号、対象年、`data/cities.json` の中心都市名、優先度、根拠、期待表現を持つ。
- 各エントリを、全政治レイヤーの同年通常面、静的 `BORROWED_FEATURES` の借用面、
  境界未収録マーカーの順にちょうど1状態へ解決する。名前の照合は台帳の明示的な
  aliasesだけを使い、自動最近傍年検索はしない。
- 借用面はraw座標を借用元と完全一致させ、配信には他領邦との差引済みflatを使う。
  通常面より低いalphaとし、ツールチップに近似、借用元年、出典、ライセンス、理由を
  表示する。
- 借用不能時は既存都市座標に専用の菱形点と「境界未収録」ラベルを置く。点は領域、
  宗主への帰属、勢力圏外周を表さない。都市・河川の可視記号と判定を優先し、点は
  背後の政治面より上にだけ置く。
- 1492←1500はマインツ、トリーア、プファルツを許可する。1458年の分割から1500年の
  再統合をまたぐヘッセンと、1495年に伯領から公領へ昇格するヴュルテンベルクは
  マーカーに留める。
- 1715←1700はプファルツ、トリーア、ヴュルテンベルクを許可する。

## 通常面への昇格手順

1. 同年面の出典、ライセンス、正準名と対象年を確認し、該当する通常政治レイヤーの
   build入力へ追加する。
2. 台帳のaliasesを通常feature名へ合わせ、`expectedRepresentation` を
   `exact-polygon` に変える。
3. 該当する `BORROWED_FEATURES` を削除し、borrowed raw/flatとfief flat/dedupeを
   再生成する。マーカーだけだった項目には削除対象の借用specは無い。
4. rawの同一性、3段階解決の一意性、既知制限、年代別inventoryを更新し、全テストと
   z4〜z6の実ブラウザ表示を確認する。同年面が認識されればresolverが借用と
   マーカーを自動抑制する。

## Consequences

- 主要領邦の存在と境界の確度を分離して伝えられ、データ欠落による無言の消失を
  防げる。
- マーカーは面を塗らないため、利用者は正確な版図を読み取れない。その制約を常時
  ラベルとツールチップで明示する。
- 対象地域の追加は台帳エントリと明示的alias/借用specの追加で行えるが、HRE以外へ
  自動適用はしない。
