# decision-47: パブリックドメイン歴史アトラスを欠落境界のトレース元に採用する

## Context

ADR-0043の3段階フォールバックは、同年面も許可済み借用面もない主要政体を境界未収録
マーカーで示す。しかし、既存4出典の追加調査でも埋まらない欠落が多数残る。

Issue #457の[一次調査](../research/issue-457-public-domain-historical-atlases.md)では、
OHMの候補222 relationと固定版Cliopatriaの13,765 featureを走査し、既存出典の
深掘りでは解消しないことを確認した。一方、Droysen 1886を中心とする著作権消滅済み
図版には、1200 / 1400 / 1492 / 1783年の欠落領邦の大半が面として描かれていた。

歴史図版のトレースは手作業で新しい座標列を作るため、出典なき座標合成を禁じる
ADR-0014 / ADR-0018、隣接年借用条件を定めるADR-0033、3段階表示を定める
ADR-0043との関係、および成果物のライセンスを先に決める必要がある。

## Decision

### 採用するソースとトレース契約

Droysen 1886、Putzgerの著作権消滅済み旧版、Shepherd 1911のPDスキャンを、既存
出典に面がない歴史的境界の新しいトレース元として採用する。次をすべて満たす図版に
限る。

1. 版、plate、描写年、取得元URL、取得日、原画像のハッシュとPD根拠を記録し、図版を
   人が目視確認している。
2. 対象政体が図版上で閉じた面として判読できる。文字位置や都市点、周辺領邦から境界
   を推測・補間しない。不鮮明部分は欠落のままとする。
3. 対象snapshotに既存採用ソースの適合する面がないことを先に確認する。OHMや
   Cliopatriaは名前一致だけで採らず、期間、bbox、geometry、既知面との位置関係を
   検査する。Cliopatria `Electorate of Trier` のIoU 0.005誤配置を回帰上の警告例と
   する。
4. トレースは図版の線を転写するだけとし、複数図版や現代境界のunion、編集者の歴史
   解釈による座標合成を行わない。図版由来の概略精度をmetadataとUIで開示する。

これはADR-0014 / ADR-0018の例外ではない。トレース元図版そのものが、地図が主張
する境界の出典である。2014年の手描き歴史地図を自動抽出したCliopatriaと同種の
品質契約として、出典固定、概略精度、選別規則、変更履歴を追跡可能にする。

### 図版年とsnapshot年

- 図版の描写年がsnapshot年と一致する面は、ADR-0043の「同年通常面」として扱う。
- 年が異なる面は差の絶対値が **25年以内** かつADR-0033と同水準の政体別検証により、
  両年の政体同一性、領域連続性、および間の有意な境界変更がないことを確認できる場合
  だけ「近似面」として扱う。検証根拠を政体単位で台帳へ記録する。
- 政体の成立・消滅、分割・再統合、称号変更に伴う領域変更、戦争・併合、または図版の
  描写年が未確定なら採らない。25年以内は必要条件であって自動採用条件ではない。
- 1195→1200（5年）、1378→1400（22年）、1477→1492（15年、描写年の確定も必要）、
  1786→1783（3年）はすべて個別検証を要する。1195↔1378の狭間にある1279年へ遠い
  図版を借りることは認めない。

通常面・近似面ともADR-0043の解決順では面としてマーカーを抑制する。ただし近似面は
既存の借用面と同じ表示上の確度とし、ツールチップに「歴史図版の別年境界による近似」、
図版描写年、対象年、版・plate、出典URL、ライセンス、連続性検証の要約を表示する。
attributionにはアトラス著者・書名・版・刊年・plate、スキャン提供元、トレース成果物の
ライセンス、変更（トレース・必要な座標系変換）を記す。同年面にも図版由来の概略境界
であることを開示する。

### ライセンス

標準経路は、権利状態を確認したPDスキャンをプロジェクトが自前でトレースし、トレース
成果物を **CC0 1.0** で提供する。この成果物はCC0レイヤーとして既存のGPL /
CC BY-NC-SA / CC BYレイヤーからファイル単位で分離し、元図の書誌情報は法的義務の
有無にかかわらずprovenanceとして表示する。

Wikimedia Commons等の第三者が作成した **CC BY-SA 4.0のSVGは標準入力にしない**。
使用する場合は自前トレースと混ぜず、CC BY-SAの独立レイヤー・派生物として分離し、
作者表示、ライセンスリンク、変更表示、ShareAlikeを満たす。その採用は対象ファイルと
配布境界を確認する別ADRまたは実装Issueで明示する。SVGを見ながら再トレースして
CC0化することも認めない。

### 適用しないケース

図版に史実上の閉じた面がない対象へ面を作らない。Droysen plates 22/23が部族大公領
だけを示すことから、1100年の三大司教領、1000/1100年のリエージュとトリーアは
マーカーまたは上位勢力に呑まれた表示を維持する。1492年のウェールズも同様とする。
「図版にない」と「面として史実を誠実に表せない」をデータ欠落と混同しない。

## Consequences

- 調査時点で未解決約121行のうち確実約88行、個別連続性検証を通る候補を含め約116行
  に、出典付き面を作る経路ができる。
- トレースは自動抽出データより編集工数が高い。後続Issueで図版単位に原画像固定、
  トレース、レビュー、metadata、attribution、台帳、表示テストを一組として実装する。
- 同年面と近似面を分けるため、利用者は境界の出典年を誤認しない。条件を満たさない
  対象にはADR-0043の境界未収録マーカーが残る。
- 本ADRは方針のみを定める。データ、パイプライン、UIは変更せず、実装は後続Issueで
  行う。
- 関連ADR: 0014、0018、0033、0043、0045。関連Issue: #444、#457。
