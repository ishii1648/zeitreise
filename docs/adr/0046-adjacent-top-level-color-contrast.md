# decision-46: 陸続きの上位勢力間にも合成後 ΔE00 10 以上を要求する

## Context

ADR-0032 は `data/colors.json` をスナップショット正とし、通常の色生成で既存キーを
動かさない。ADR-0041 は例外として、塗りを `FILL_ALPHA = 128` で羊皮紙陸地色
`#f0e6cd` へ合成した表示色と、素の陸地色との CIEDE2000 色差を
**ΔE00 10 以上**にした。しかし、隣接する上位勢力どうしの色差は制約していない。

France `#6c9d70` と Holy Roman Empire `#789d6c` はそれぞれ陸地から判別できる
一方、合成後の相互色差が **2.026** しかなかった。概略境界は位置精度を誤認させない
ために低 alpha・blur 付きなので、近似色の面が接すると静止画で外周を追いにくい。

## Decision

### 隣接グラフ

全 19 件の `europe_<year>.geojson` を対象に、ランタイムの概観塗りと同じ
「宗主補正 > `SUBJECTO` > `NAME`」で上位勢力を解決する。異なる feature の
Polygon / MultiPolygon 境界線分が、共線上で**正の長さ**を共有するときだけ辺を
張る。長辺の途中に頂点を持つ T 字接合は部分線分の重なりとして拾い、端点だけの
接触、海峡越し、他 feature と共有されない沿岸外周は除く。空間格子で候補線分を
絞り、年・勢力名をソートして入力順に依存しない結果を返す。

実データでは延べ **1,207 辺**、年代間で重複を除くと **630 ペア**になった。

### 色差と一回限りの再割当て

判定色は ADR-0041 と同じ source-over 合成後の色とし、全隣接ペアに
**ΔE00 >= 10** を要求する。閾値を揃える理由は、国境を挟んだ別の面を、少なくとも
「塗りと羊皮紙」と同程度に判別可能にするためである。別の尺度や alpha を導入せず、
ADR-0041 の色計算を共有する。

適用前は 630 ペア中 **169 ペア / 142 上位勢力**が違反していた。
`--remap-adjacent` の明示フラグだけが一回限りの是正を行う。初期違反辺の端点に
属する色ファミリーだけを可動にし、羊皮紙 ΔE00、同年の色衝突、確定済み隣接色との
ΔE00 を満たすパレットスロットを決定的に選ぶ。高次数の勢力から割り当て、後続の
現在色と衝突しにくい候補を優先する。属領キーは新しい宗主色から従来どおり明度を
ずらして再導出する。

France–HRE は色相でも分けるため、France は青緑（目標 H=180°）、HRE は黄味の
オリーブ（目標 H=85°）を優先する。この明示回帰を全隣接制約と両立させるため、
France の青緑候補と近かった Navarre / Palatinate / Pontremoli の 3 勢力も同時に
可動にする。これは初期違反端点以外を動かす唯一の例外である。

適用結果は **197 / 550 キー変更**（うち属領 62）。142 違反勢力に対応するキーと
その属領・別綴りの導出値に加え、巻き添えは 6 キーである。内訳は上記 3 勢力と、
色ファミリー追随の別綴り 3 キー（`Baltic Tribes|Baltic tribes`、
`Kievan Rus|Kyivan Rus`、`Poland-Lithuania|Poland-Llituania`）。非対象キーは
バイト単位で維持する。適用後の再実行と通常の `--check` はともに diff 0 になる。

France は `#6c9d70` から `#bfe3e2`、HRE は `#789d6c` から `#b5c577` となり、
相互色差は **2.026 → 12.686**。全ペアの是正後最小は Austria–Venetia の
**10.025**である。

### 境界の小幅強調

配色制約とは独立に、概略境界の既存文法を保ったまま次だけを変更する。

- normal ink: alpha 0.62 → 0.70、幅 1.0px → 1.2px、blur 0.6px 据え置き
- long casing: overview alpha 0.16 → 0.22、detail alpha 0.09 → 0.13
- long casing の幅・blur、long ink、very-long ink は据え置き

normal → long → very-long の順に低 alpha・太線・強い blur となる不確実性階層、
および上位勢力外周 > 構成勢力境界 > 下位境界の階層は自動テストで固定する。

## Consequences

- ADR-0032 のスナップショット正は維持される。通常実行は既存キーを動かさず、今回の
  例外は `--remap-adjacent` の明示実行に限る。
- ADR-0041 の羊皮紙色差・パレット格子・属領ファミリー契約を変更せず、その色計算を
  面どうしへ拡張する。
- 新しい年代・境界・色キーが追加され、隣接 ΔE00 10 を割ると実データ監査が失敗する。
- パレット候補 193 色の中で全 630 ペアの制約が成立する。将来成立しなくなった場合は
  同色や低色差へ縮退せず、生成処理を例外で停止する。
- normal 境界は追いやすくなるが、全 tier の blur と long / very-long ink は不変なので
  境界位置を精密線として見せない設計は維持される。
