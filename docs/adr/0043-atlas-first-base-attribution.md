# decision-43: base 帰属と低ズーム国名は歴史図譜の慣行を第一則として判定する

## Context

`europe_1000/1100.geojson` の `Kingdom of France` は、カペー王の実効支配が
及ばないアキテーヌ、トゥールーズ、ブルゴーニュ、アンジュー等も含む名目上の
王国枠である。一方、ノルマンディーだけは TASK-101 で実効支配を重視して
`BASE_FIEF_SPLITS` により独立 feature へ切り出した。ブルターニュは上流由来の
独立 feature に decision-19 の `suzerains` 補正を加えた中間的な表現であり、
同じ地図の中で base 帰属の判定基準が揃っていない。

逆に、16 世紀以降も法的には帝国封土であった帝国イタリア
（Reichsitalien）を 1806 年まで神聖ローマ帝国の base に含めると、一般的な
歴史図譜の表現から外れる。「常に名目上の宗主へ寄せる」「常に実効支配者へ
寄せる」のいずれかを単一原理にすると、別の地域で不自然な結果になる。

base の塗り、最大ズームアウト時の国名ラベル、勢力圏の外枠は相互に一つの
政治的な大枠を表す。この大枠を地域ごとの都合で決めるのではなく、個々の結論が
異なっても、判定手続きと根拠の記録方法を一貫させる必要がある。

## Decision

### 判定手続き

base の帰属、最大ズームアウト時の国名、勢力圏の外枠は、次の順序で判定する。

1. **第一則は、その時代を扱う主流の歴史図譜の慣行とする。** Putzger、
   Westermann、Shepherd 等、対象時代・地域を広域図として扱う図譜を比較し、
   国名と外枠が通常どの政治的単位へ与えられているかに従う。一つの図だけを
   恣意的に選ばず、参照した版・図・対象年代を記録する。
2. **図譜の慣行が割れる、または図譜が対象関係を示さない場合に限り、宗主権が
   政治的に機能していたかをフォールバックとして判定する。** 指標は、臣従礼・
   投封の実施、宗主による域内介入、中央機構への参加、同時代の政治的呼称とする。
   単一の指標ではなく、利用できる指標を組み合わせて結論を出す。
3. **すべての個別判定を ADR または `docs/data-inventory/` に記録する。** 対象の
   年代と地域、採用した帰属、参照図譜、図譜間の一致・相違、フォールバックを
   使った場合の各指標、採らなかった表現方法を残す。これは decision-14 / 18 の
   「出典なき合成をしない」という原則を、政治的帰属の解釈にも適用するものである。

この手続きは「名目」か「実効」かを全地域で統一するものではない。図譜という
共通の第一則、必要な場合だけ用いる共通のフォールバック、根拠の記録義務を
統一する。

### ズーム階層の意味

低ズームの base、国名、勢力圏外枠は、広域を理解するための**名目的・上位の
政治的枠組み**を基本として表す。高ズームでは、既存の諸侯領オーバーレイにより
**実効支配の区画**を表す。したがって低ズームから高ズームへの遷移は、同じ情報の
単なる詳細化ではなく、上位の政治枠から域内の支配区画へ視点を移す意味を持つ。

個別判定で採らなかった側の情報も捨てない。実効支配側はズームイン時の諸侯領
オーバーレイ、名目的な宗主関係は `suzerain_extent`、補足が必要な差異は情報
パネルの注記で表す。どの副次機構を使うかも個別判定の記録に含める。

### 本 ADR で確定する個別判定

| 対象 | base・低ズーム国名・外枠の判定 | 根拠 |
| --- | --- | --- |
| 11 世紀フランス | ノルマンディーを含む名目枠のフランス王国へ寄せる | 中世フランスを王国の枠で示す Putzger / Westermann / Shepherd 等の広域図の慣行に従う。フォールバック指標でも、公による臣従礼・投封、1054 / 1057 年の国王によるノルマンディー遠征という域内介入、同時代の `regnum Francorum` という王国枠があり、宗主権は政治的に機能していたと判定する。公領の実効支配は高ズームの諸侯領オーバーレイで残す。 |
| 16 世紀以降の帝国イタリア | 神聖ローマ帝国の base・低ズーム国名・外枠に含めず、実効側へ寄せる | 帝国イタリアを帝国の一体的な塗りから外す主流の歴史図譜の慣行に従う。フォールバック指標でも、帝国議会に議席を持たず、帝国クライス外で、帝国税を負担せず、宗主権の作用は Reichshofrat における授封・封建訴訟等に限られるため、低ズームの政治的一体性を表すほど機能していないと判定する。法的な帝国封土という関係は注記等で保持する。 |

## Consequences

- decision-19 の `suzerains` を「上流にない、歴史的に明白な宗主関係の追加」に
  限る基準は維持する。本 ADR は、宗主関係を追加できるかではなく、base・低ズーム
  国名・外枠をどの政治的単位へ寄せるかを先に決める上位の判定方針となる。
- decision-20 の `propertyFixes = 上流値の訂正` / `suzerains = 上流にない関係の
  追加` という機構の分担は維持する。本 ADR の判定後、必要な実装手段を選ぶ際に
  decision-20 を適用する。
- TASK-101 のうち、出典付き区画を `BASE_FIEF_SPLITS` で切り出す機構と、高ズームで
  ノルマンディー公領を表現する目的は維持する。しかし 1000 / 1100 年の
  ノルマンディーを base 上の独立勢力とした個別判断は、本 ADR の 11 世紀フランス
  判定により覆る。ノルマンディーだけを実効支配基準で王国枠から除くと、同じ
  `Kingdom of France` 内の他の大諸侯領および主流図譜の王国表現と基準が揃わない
  ためである。
- TASK-101 の実装を戻すデータ・コード変更、および `docs/app-spec.md` の切り出し表・
  根拠記述の更新は後続 Issue で行う。本 ADR では方針と個別判定のみを確定する。
- 今後、base 帰属に解釈が必要な地域を追加・変更する場合は、実装と同時に上記の
  記録項目を ADR または data-inventory へ追加しなければならない。
